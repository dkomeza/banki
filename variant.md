# c: Register

A compact register, newest first: a table from 768 px (name with kind and what went, Was in, Deleted, a days-left chip) and stacked rows on phones; Restore in view and Delete permanently one step away in each row's ⋯ menu; a refused Restore opens a dialog offering "Restore German verbs"; reached from a "Recently deleted" section on Settings (Settings stays current in the nav), with a back link to Settings.

States: empty, restored, restored-root, restored-renamed, refused, delete (on `/deleted`); undo (on `/`)

Prototype only: the list is the spec's Seed Deletions held in the page (no API yet), so Restore and Delete permanently last until a reload, and the Settings card's figures are fixed.
