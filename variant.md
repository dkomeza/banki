# f: Covers

Bet: builds on b, Shelf, and gives every deck a face: Home is a shelf of covers, each deck's monogram on ruled paper with its name and the start of its description under it, so you find a deck by sight; the sort and "New deck" share the title's row, and create and edit stay in b's dialog (a sheet on phones); the deck page opens with the same cover beside the name and description, on the page rather than in b's card, with Edit and Delete under them.

States: `/`: `empty`, `create`, `create-taken`, `newest`. `/decks/$deckId`: `edit`, `delete`, `no-description`, `not-found`.
