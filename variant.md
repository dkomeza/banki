# d: Icon grid

c's Floating with the round-1 tweaks, betting on a ⋯ menu that reads as a small grid of icons: one row per thing it acts on (Row, Column, Align, Table), each named once in the margin's small caps, with every delete in red at the end of its row and a tooltip naming each icon on desktop. The toolbar pill sits centred on the focused side's top edge, in a gap kept for it above each side; a side being written has no orange outline, its label in the margin turns to ink instead.

States: inline-editing, display-editing, broken, table, table-menu, toolbar
