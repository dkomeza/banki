# c: Index

Bet: a deck list should read like a book's index: Home groups the decks under their first letter (Alphabetical) or the month they were made (Newest), one card per group, names only, with the sort a quiet menu and "New deck" opening its form in place; the deck page is a page of cards like Settings, with Cards first and "About this deck" (name and description as rows with Edit beside them, the form opening in place) and "Delete deck" beside it.

States: `/`: `empty`, `create`, `create-taken`, `newest`. `/decks/$deckId`: `edit`, `delete`, `no-description`, `not-found`.
