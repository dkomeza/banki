## Agent skills

### Issue tracker

Issues live in Linear (team BAN, project "Banki") via the `linear-banki` MCP (`mcp__linear-banki__*`); ask before creating any. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Working on an issue

Use the `work-issue` skill (`/work-issue BAN-N`): grill, implement in a worktree under `../banki-worktrees/`, adversarial review, PR, CodeRabbit.
